# zahnarztcuxhaven

Next.js (App Router) + TypeScript + Tailwind CSS initialized.

## Run

1. `npm install`
2. `npm run dev`
3. Open `http://localhost:3000`

## Design system

Defined in [tailwind.config.ts](tailwind.config.ts):

- `primary-blue`
- `accent-blue`
- `light-bg`
- `status-green`

Global app container (`max-width: 1200px`) is defined in [app/globals.css](app/globals.css) as `.app-container`.
